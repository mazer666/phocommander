# Glossary — Begriffe / Terms

Terms that carry a specific meaning in Phocommander. Each entry has a German and an
English line with the same content, so that the document can be read in either
direction without a translation step.

The binding source for every definition is
[`docs/REQUIREMENTS.md`](REQUIREMENTS.md). Where a term comes from an external
standard or platform, that source is named in the entry.

---

| Begriff / Term | Deutsch | English |
|---|---|---|
| **Panel** | Eine der beiden Hälften der Arbeitsfläche. Ein Panel zeigt Pfad, Dateiliste und Spalten und besitzt eine aktive Registerkarte, einen Pfad, eine Cursorposition, eine Sortierung, eine Auswahlmenge und einen Ansichtsmodus. Operationen wirken immer auf das *aktive* Panel. | One of the two halves of the workspace. A panel shows path, file list and columns, and owns an active tab, a path, a cursor position, a sort order, a selection set and a view mode. Operations always act on the *active* panel. |
| **Registerkarte (Tab)** | Ein Reiter am Rand eines Panels. Jede Registerkarte hält einen eigenen Verzeichnispfad, eine eigene Sortierung und eigene Anzeigeeinstellungen, und sie lässt sich zwischen den beiden Panels verschieben. | A tab at the edge of a panel. Each tab holds its own directory path, its own sort order and its own display settings, and it can be moved between the two panels. |
| **Auftrag (Job)** | Ein Vorgang, den die Auftragswarteschlange im Hintergrund ausführt. Ein Auftrag hat Typ, Status, Fortschritt, Ratenangabe, Abbruchflagge und Fehlerliste; die Warteschlange ist threadsicher, die Oberfläche liest einen Snapshot. Mehrere Aufträge laufen parallel bis zu einem konfigurierbaren Limit. | An operation executed by the job queue in the background. A job has a type, a status, progress, a rate, a cancel flag and an error list; the queue is thread-safe and the interface reads a snapshot. Several jobs run in parallel up to a configurable limit. |
| **Aktion (Action)** | Eine benannte, bedienbare Funktion mit stabiler Aktions-ID in Punktnotation, zum Beispiel `panel.copy` oder `selection.toggle`. Die Eingabeschicht übersetzt physische Eingaben in Aktions-IDs; die Oberfläche kennt ausschließlich die IDs und weiß nicht, ob eine Aktion per Taste, Klick, Wischgeste, D-Pad-Taste oder Controller-Trigger ausgelöst wurde. | A named, operable function with a stable action ID in dotted notation, for example `panel.copy` or `selection.toggle`. The input layer translates physical input into action IDs; the surface layer knows only the IDs and never knows whether an action was triggered by a key, a click, a swipe, a D-pad direction or a controller trigger. |
| **Aktionspalette (Action Palette)** | Eine durchsuchbare Liste aller Aktionen, die im aktuellen Bedienkontext verfügbar sind. Sie ersetzt auf Fernbedienungen und Controllern die F-Tastenreihe, wird über die Menü- oder die Play/Pause-Taste geöffnet und ist vollständig mit Richtungstasten und OK bedienbar. Sie filtert nach Kontext: eine Aktion, die eine gedrückte Umschalt-Taste braucht, erscheint im `dpad`-Kontext nicht. | A searchable list of all actions available in the current input context. It replaces the row of function keys on remote controls and controllers, opens with the menu or the play/pause key, and is operated entirely with the direction keys and OK. It filters by context: an action that needs a held shift key does not appear in the `dpad` context. |
| **Bedienkontext (Input Context)** | Die Art der Eingabe, über die ein Gerät bedient wird: `keyboard`, `pointer`, `touch`, `dpad` oder `controller`. Jeder Kontext hat eine eigene Vorgabe je Aktion, damit dieselbe Anwendung auf einem Laptop, einem Tablet und einem Fernseher richtig bedient wird. | The kind of input through which a device is operated: `keyboard`, `pointer`, `touch`, `dpad` or `controller`. Every context has its own default per action, so that the same application is operated correctly on a laptop, a tablet and a television. |
| **Platzhalter (Placeholder)** | Ein Textbaustein in der Umbenennungsregel, der beim Umbenennen durch einen Wert ersetzt wird: `[name]`, `[ext]`, `[parent]`, `[n]`, `[date]`, `[time]`, `[size]`, `[hash]`, `[rand]` sowie `[case]`, `[lower]`, `[upper]`, `[title]` für die Groß- und Kleinschreibung. Platzhalter werden vor den Ersetzungsregeln und dem Zähler ausgewertet. | A building block in a rename rule that is replaced by a value when the rename runs: `[name]`, `[ext]`, `[parent]`, `[n]`, `[date]`, `[time]`, `[size]`, `[hash]`, `[rand]`, and `[case]`, `[lower]`, `[upper]`, `[title]` for letter case. Placeholders are evaluated before the replacement rules and the counter. |
| **Konfliktsprung** | Das Springen zwischen den berechneten Namen, die im Zielverzeichnis bereits existieren. Die Konflikte sind im Umbenennungsdialog farblich markiert und in einer eigenen Konfliktsprung-Liste geführt; `F3` springt zum nächsten, `Shift+F3` zum vorherigen Konflikt. | The jumping between computed names that already exist in the target directory. Conflicts are colour-marked in the rename dialog and kept in a separate conflict-jump list; `F3` jumps to the next conflict, `Shift+F3` to the previous one. |
| **Kontextmenü** | Das Menü mit den Aktionen, die für den markierten Eintrag verfügbar sind. Es wird über den Rechtsklick oder über die Menüaktion geöffnet; was der Rechtsklick tut, ist über `right_click_action` einstellbar. | The menu with the actions available for the marked entry. It is opened with the right click or through the menu action; what the right click does is configurable via `right_click_action`. |
| **Virtuelles Verzeichnis** | Der Inhalt eines Archivs, dargestellt in einer Panel-Hälfte wie ein Verzeichnis. Die enthaltenen Dateien sind auflistbar, anzeigbar und in die andere Panel-Hälfte kopierbar, ohne dass das Archiv vorher entpackt werden muss. | The contents of an archive, shown in one pane like a directory. The files inside can be listed, viewed and copied to the other pane without the archive being unpacked first. |
| **Dateiablage** | Ein Ablageort, an dem häufig benötigte Dateien unabhängig von ihrem Fundort gesammelt werden. | A drop point where frequently needed files are collected, independent of where they were found. |
| **Eingabezeile** | Das Eingabefeld am unteren Rand der Oberfläche. Es nimmt Pfade und Shell-Kommandos entgegen und ist mit einer Kommandozeilenhistorie (`Ctrl+Down`) und einem Befehlsausgabefenster verbunden. | The input field along the bottom edge of the interface. It accepts paths and shell commands and is connected to a command-line history (`Ctrl+Down`) and a command output window. |
| **Quellpanel / Zielpanel** | Das Quellpanel ist das Panel, aus dem heraus kopiert oder verschoben wird; das Zielpanel ist das Panel, in das hinein kopiert oder verschoben wird. Der Wechsel des Zielpanels erfolgt ausdrücklich — über `Ctrl+Enter` oder per Drag & Drop — damit keine Datei versehentlich im falschen Verzeichnis landet. | The source panel is the panel a file is copied or moved *from*; the target panel is the panel it is copied or moved *to*. The hand-over to the other panel is always explicit — via `Ctrl+Enter` or drag and drop — so that no file ends up in the wrong directory by accident. |
| **Clear / Purge / Destroy** | Die drei Stufen der Datenbereinigung nach **NIST SP 800-88 Rev. 2**. *Clear* (logisches Überschreiben) ist die Standardstufe in Phocommander und wird als „sicheres Löschen" bezeichnet; *Purge* überschreibt mehrfach; *Destroy* zerstört das Medium. Auf Flash-Medien ist Überschreiben nicht zuverlässig, weil Wear-Leveling die Zellen umverteilt — diese Einschränkung steht in der Oberfläche, nicht nur im Handbuch. | The three levels of media sanitization defined by **NIST SP 800-88 Rev. 2**. *Clear* (logical overwrite) is the default level in Phocommander and is what "secure delete" means here; *Purge* overwrites repeatedly; *Destroy* destroys the medium. On flash media an overwrite is not reliable, because wear levelling redistributes the cells — that limitation is stated in the interface, not only in the manual. |
| **Security-scoped URL** | Eine URL mit Berechtigungsrahmen auf iPadOS. Sie entsteht, wenn der Nutzer über den Dokumenten-Picker ein Verzeichnis freigibt, und erlaubt den Zugriff auf dessen Inhalt — rekursiv und nur im Umfang der Freigabe. Für die dauerhafte Nutzung wird sie als security-scoped Bookmark gespeichert; der Nutzer kann den Zugriff jederzeit entziehen. | A URL with a permission scope on iPadOS. It is created when the user grants access to a directory through the document picker, and it permits access to that directory's contents — recursively, and only within the granted scope. For permanent use it is stored as a security-scoped bookmark; the user can revoke the access at any time. |
| **Scoped Storage** | Das Zugriffsmodell von Android ab API 30: Eine App sieht von außen nur Dateien, die ihr gehören oder die der Nutzer über das Storage Access Framework ausgewählt hat. Der Storage Access Framework ist der empfohlene Weg; die Alternative ist die Spezialberechtigung `MANAGE_EXTERNAL_STORAGE`. | The access model of Android from API 30 onwards: an app sees from outside only the files it owns or that the user has selected through the Storage Access Framework. The Storage Access Framework is the recommended path; the alternative is the special permission `MANAGE_EXTERNAL_STORAGE`. |
| **All-files access** | Die Android-Berechtigung `MANAGE_EXTERNAL_STORAGE`, in der Play-Verwaltung „Alle Dateien" genannt. Sie erlaubt den Zugriff auf das gesamte gemeinsame Speichervolumen. Google nennt die Dateiverwaltung ausdrücklich als zulässigen Anwendungsfall; die Berechtigung braucht trotzdem eine Erklärung, einen Manifest-Eintrag und die Freigabe durch den Nutzer. Phocommander funktioniert auch ohne sie — dann im Dokumenten-Browser-Modus. | The Android permission `MANAGE_EXTERNAL_STORAGE`, called "all files" in the Play Console. It grants access to the entire shared storage volume. Google explicitly names file management as a legitimate use case; the permission still requires an explanation, a manifest entry and the user's consent. Phocommander works without it as well — then in document-browser mode. |
| **D-Pad** | Das Kreuz aus Richtungstasten auf einer TV-Fernbedienung. Google Play prüft TV-Anwendungen darauf, ob die gesamte Funktionalität mit einem Fünf-Wege-D-Pad und der Zurück-Taste erreichbar ist. Der `dpad`-Bedienkontext von Phocommander ist deshalb eine vollwertige Bedienart und keine Notlösung. | The cross of direction keys on a TV remote control. Google Play checks TV applications for whether the complete functionality is reachable with a five-way D-pad and the back button. The `dpad` input context of Phocommander is therefore a full operating mode, not a fallback. |
| **10-Fuß-Oberfläche (10-foot UI)** | Eine Oberfläche, die aus etwa drei Metern Entfernung bedienbar ist: große Schriftgrößen, deutlich kräftigere Fokusrahmen, sichtbare Bedienhinweise („OK öffnet, Zurück geht zurück"). Im `dpad`-Kontext ist nur **ein** Panel sichtbar, weil zwei gleichzeitige Panels auf einem Fernseher unlesbar wären. | An interface that can be operated from about three metres away: large type, markedly stronger focus frames, visible operating hints ("OK opens, Back goes back"). In the `dpad` context only **one** pane is visible, because two simultaneous panes would be unreadable on a television. |
| **Flat Panel** | Die räumliche Darstellungsform einer Horizon-OS-Anwendung: eine flache, freistehende Fläche im Raum. Touch-Gesten wie Tippen, Wischen, Scrollen und Pinchen werden vom System auf Controller- und Hand-Tracking-Eingaben abgebildet. Phocommander nutzt diese Form auf der Android-Version, statt einen immersiven VR-Port zu bauen — im Panel-Modus gibt es keine Tastatur, und diese Einschränkung wird in der Dokumentation ausgewiesen. | The spatial form of a Horizon OS application: a flat, free-standing surface in the room. Touch gestures such as tapping, swiping, scrolling and pinching are mapped by the system onto controller and hand-tracking input. Phocommander uses this form on the Android version instead of building an immersive VR port — in panel mode there is no keyboard, and that limitation is stated in the documentation. |
