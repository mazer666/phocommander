# Acceptance criteria — Phocommander M0, M1 and M2

This document holds exactly one acceptance criterion for every requirement of the milestones `M0`, `M1` and `M2` of the catalogue in [`REQUIREMENTS-IDS.md`](REQUIREMENTS-IDS.md). The pattern follows section 13 of [`REQUIREMENTS.md`](REQUIREMENTS.md): every criterion names a command or an operation sequence that a reviewer can repeat, and every statement of a result is evidence.

## How to read the criteria

| Column | Meaning |
|---|---|
| ID | `AC-M<n>-<nn>` — the criterion belongs to the milestone `M<n>`; the number runs without a gap inside the milestone. |
| FR-ID | The requirement of [`REQUIREMENTS-IDS.md`](REQUIREMENTS-IDS.md) this criterion belongs to. |
| How to Verify | The exact command or the exact operation sequence. A criterion that cannot be automated is marked `[manual]` and describes the step in full. |
| Pass Condition | A measurable statement. No "works", no "is implemented", no "should be fine". |
| Milestone | The milestone that delivers the requirement. |
| Evidence | The state of the criterion at the time of writing. |

## Rules for the evidence column

| Marker | Meaning |
|---|---|
| `PASS — <what was executed>` | The criterion was executed and the result is quoted in `deliverable.md` or stored under `docs/acceptance/logs/`. |
| `PARTIAL — <what was executed> ; <what could not be executed and why>` | One part of the criterion was executed and passed, the other part could not be executed and names the reason. A PARTIAL is not a PASS. |
| `NOT RUN — <exact reason>` | The criterion could not be executed. The reason names exactly what is missing. A NOT RUN with a reason is allowed and honest; a faked PASS is not. |

A command that names a test which does not exist yet counts as `NOT RUN`, never as a pass. The crates of the workspace exist since M0, but the behaviour that a criterion names arrives with the milestone that the requirement carries; the reason of every `NOT RUN` names that milestone and the crate that does not implement the behaviour yet.
